# SQL Sakila DVD Rental Analysis

## 📌 Project Overview
This project analyzes the Sakila DVD Rental database using SQL to extract insights about customer behavior, revenue patterns, store performance, and country-level revenue distribution.

The analysis uses advanced SQL techniques such as JOINs, CTEs, window functions, and aggregations.

---

## ❓ Business Questions Answered

1. What is the average difference between monthly spending and the yearly average per customer?
   - Analyzed customer spending behavior by comparing monthly payments to yearly averages.

2. Which film categories generate above-average revenue?
   - Identified film categories that perform above the overall average revenue.

3. Which store generates above the company’s average store revenue?
   - Compared total revenue across stores and identified high-performing stores.

4. Rank the top 5 countries based on total customer revenue.
   - Ranked countries according to total revenue generated from customers.

---

## 📊 Key Insights

- Customer spending varies significantly across months.
- Certain film categories consistently outperform others in revenue.
- Store performance differs, with some stores exceeding the company average.
- Revenue is concentrated in specific countries.

---

## 🛠️ SQL Techniques Used

- JOIN operations (multiple table relationships)
- Common Table Expressions (CTEs)
- GROUP BY aggregations
- Window functions (AVG, RANK)
- CASE statements for classification
